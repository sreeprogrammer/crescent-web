# Elevate University

I have attached the screenshot of my existing college website. Do not clone this design. Use it only to understand the content, layout, and section order.

Redesign it as a premium 2026 university website with a modern, elegant, and world-class UI inspired by Apple, Vercel, Linear, Stripe, Harvard, Stanford, and MIT. The website should feel luxurious, minimal, and professional with excellent UX.

Requirements:

 React + Vite

 Tailwind CSS

 Framer Motion for animations

 Shadcn UI components

 Lucide React icons

 Fully responsive (Desktop, Tablet, Mobile)

 Reusable React components

 Clean folder structure

Design Style:

 Glassmorphism

 Soft gradient backgrounds

 Large whitespace

 Rounded corners (24–32px)

 Premium typography (Poppins for headings, Inter for body)

 Floating cards

 Modern shadows

 Smooth scroll animations

 Hover effects

 Sticky glass navbar

 Premium buttons with subtle glow

Homepage Sections:

 Announcement Bar

 Glass Navbar

 Hero Section with large campus image and floating statistic cards

 University Statistics (animated counters)

 Featured Programmes

 Why Choose Our University

 Campus Life / Gallery

 Faculty Showcase

 Research & Innovation

 Placement Highlights

 Student Testimonials

 Latest News & Events

 Admission Process

 FAQ

 Call-to-Action

 Premium Footer

Animations:

 Fade-in on scroll

 Card hover lift

 Image zoom on hover

 Animated counters

 Smooth page transitions

 Floating background shapes

Quality Goal:
The final result should look like a top international university website released in 2026, not a traditional college website. Prioritize visual quality, accessibility, responsiveness, clean code, and reusable components over copying the original design.
